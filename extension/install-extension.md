# 🚀 Install Productivity Harnesser Browser Extension

## Chrome Installation

### Step 1: Enable Developer Mode
1. Open Chrome and go to `chrome://extensions/`
2. Turn on **Developer mode** (toggle in top right)
3. Click **Load unpacked**

### Step 2: Select Extension Folder
1. Navigate to: `/Users/elcdevmbp/IS_581/ProductivityHarnesser/extension`
2. Click **Select Folder**

### Step 3: Pin the Extension
1. Click the puzzle piece icon in Chrome toolbar
2. Find "Productivity Harnesser" and click the pin icon
3. The extension icon will appear in your toolbar

## Firefox Installation

### Step 1: Enable Developer Mode
1. Open Firefox and go to `about:debugging`
2. Click **This Firefox**
3. Click **Load Temporary Add-on**

### Step 2: Select Manifest
1. Navigate to: `/Users/elcdevmbp/IS_581/ProductivityHarnesser/extension`
2. Select `manifest.json`
3. Click **Open**

## How It Works

### 🎯 **System-Wide Blocking**
- Blocks distracting websites across **ALL tabs and windows**
- Works even if you try to open new tabs
- Redirects blocked sites to a motivational page

### 📝 **Daily Goal Requirement**
- Must set meaningful goals each morning
- App locks until goals are completed
- Goals reset at midnight each day

### 🛡️ **Default Blocked Sites**
- Facebook, Instagram, YouTube, Twitter, TikTok
- Reddit, Netflix, Twitch, Discord, Snapchat
- Pinterest, LinkedIn feed, 9gag, Imgur
- BuzzFeed, Daily Mail, HuffPost, TMZ

### ⚡ **Quick Controls**
- Click extension icon for popup controls
- Toggle blocking on/off
- Set daily goals
- View focus statistics

## Usage

### Morning Routine
1. **Click the extension icon**
2. **Set your daily goals** (minimum 10 characters)
3. **Enable blocking** if not already on
4. **Start your focused work day!**

### During the Day
- **Blocked sites** will show a motivational page
- **Extension popup** shows your progress
- **Goals reminder** keeps you focused

### Emergency Access
- **Temporary bypass** available (5 minutes)
- **Edit goals** to unlock if needed
- **Toggle blocking** off if necessary

## Troubleshooting

### Extension Not Working?
1. **Refresh the page** after installing
2. **Check extension permissions** in browser settings
3. **Restart your browser**
4. **Reinstall the extension**

### Sites Not Being Blocked?
1. **Check if goals are set** for today
2. **Verify blocking is enabled** in popup
3. **Try refreshing the page**
4. **Check if site is in blocked list**

### Goals Not Saving?
1. **Check browser permissions**
2. **Try setting goals again**
3. **Restart the extension**
